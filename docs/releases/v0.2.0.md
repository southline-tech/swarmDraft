## What's new in 0.2.0 (pilot)

This is the **pilot build** for our first novelist test. It finishes the MVP writing experience we planned after the early 0.1.x builds: import your book, edit with autosave, work with named writing assistants, and stay on plain author wording throughout the app.

### Install and first run

- **Per-user installer** — Setup does not ask for an administrator password. Your manuscripts stay in your Windows user folder.
- **Welcome screen** — On first launch, **Get started** walks you into opening or importing a book.
- **SmartScreen** — Unsigned builds may show **Windows protected your PC**. Choose **More info**, then **Run anyway** (see [install-author.md](../install-author.md)).

### Bring your Word manuscript

- **Import a Word file** (`.docx`) from the welcome flow or **Open** — drag-and-drop or file picker. Your **original Word file on disk is not changed**; swarmDraft works on its own copy inside the app.
- **Faster import** for large books, with a **progress screen** while the file opens so you know work is happening.
- **Clear error messages** if something goes wrong with import — plain language, not technical codes.

### Writing like a word processor

- **Sections and chapters** — Outline navigation, split and merge chapters, and continuous scrolling where you expect it.
- **Autosave** — Edits are **saved** as you work; the footer shows save status so you can trust the text is on disk.
- **Reopen your last book** after you close and restart the app.
- **Save as `.draft`** — Optional book package you can save and open again; includes history inside the file (see below).
- **Export** from Settings — Word (`.docx`) and EPUB where enabled; print PDF may still show as coming later in this pilot.

### Writing assistants (coAuthors)

- **Pair named bots** in **Settings → Agents** — each assistant gets a visible name in suggestions and comments.
- Assistants only **suggest** changes; **you accept or reject** before any text changes.
- **Comments and review marks** work alongside your own edits.

### Updates

- **Check for updates** from the book menu (and background checks). When a newer build is available, **Update now** installs it and reopens the app — your saved manuscripts are not removed.

### Reliability and polish in this release

- **Copy and labels** across the app match the author-facing wording spec (saved, Word file, no jargon in the UI).
- **Empty states** for review, comments, and notes so blank panels explain what to do next.
- **In-app feedback** — **Send feedback** in the book menu or Settings to report bugs or UX issues.

### `.draft` book files (new)

- **Save to `.draft`** to keep a whole book in one file you can move or back up like any other document.
- **History inside the file** — Recent snapshots are stored in the `.draft` package so you can recover earlier versions without leaving the app.
