## Unsigned build

Windows SmartScreen: **More info → Run anyway** (see [install-author.md](../install-author.md)).

macOS builds are unsigned too. After you drag swarmDraft to Applications, Control-click it
and choose **Open**, then **Open** again. If macOS only offers **Move to Trash** or **Done**,
open **System Settings → Privacy & Security** and choose **Open Anyway**. You only need this
the first time. See [install-macos.md](../install-macos.md).

Install: [Releases](https://github.com/southline-tech/swarmDraft/releases/latest) — verify
`SHA256SUMS.txt` (Windows) or `SHA256SUMS-macos.txt` (macOS) on the release if you want a
checksum check.

## What's new in 0.2.2 (pilot QA)

This update fixes problems found while checking 0.2.1 on Windows, and it changes how review,
history, and bot suggestions are stored in your book. Your writing stays on this computer.
This build is for QA only.

A `.draft` book file saved in an earlier build will not open in 0.2.2. This pilot does not
convert older book files. Start a new book in this build, or import your Word file again.

### Saving

- **Ctrl+S always tries to save** — When the red “changes aren't saved yet” banner is showing,
  Ctrl+S and Save try again. If the save works, the banner goes away and your book file is written.
  If it still can't, you see that same plain warning instead of nothing happening.
- **Save As can be repeated** — You can open Save As, cancel, and run it again. A failed attempt
  doesn't leave Save As stuck.

### Bots and review

- **Suggestions answer quickly** — When a bot suggests an edit, the tool returns the suggestion id
  right away, even if the app is busy saving.
- **Quotes with apostrophes match** — A quote like “X's” matches the same words when the book uses
  a curly apostrophe, and the other way around. Straight and curly double quotes match too.
- **History lives in the book** — Sessions, comments, and your accept or reject history are stored
  in the book, so they come back when you reopen it.
- **Each decision is saved** — When you accept or reject a bot suggestion, that choice is saved
  right away. The bot's set of suggestions is finished only after you have decided every one of
  them. Rejected suggestions stay in History, marked rejected — they are not erased.
- **Links to a change** — A `swarmdraft://` link can open your book on one tracked change,
  including after you have accepted or rejected it.
- **Links to a review list** — A bot can send a link that opens Review filtered to the changes it
  named. A chip shows how many selected changes are in the list; Clear takes the filter off.

### macOS

- **Unsigned disk image for QA** — You can install swarmDraft on a Mac from a disk image. The
  build is unsigned, so macOS will warn the first time you open it (see above).

### Polish

- **Disabled actions stay in the menu** — When you can't merge a chapter or open History yet, the
  item stays visible with a short reason, instead of disappearing.
- **Track changes is one switch for the whole book**, and it is listed on the shortcuts sheet.

### Known issues

- After you edit near an open suggestion and reopen the book, the highlight can land on the wrong
  text. Tracked in #348.

**Updating from 0.2.1:** Use **Check for updates** in the book menu, or install the latest build
from GitHub Releases. Your manuscripts and settings in the app are kept. A `.draft` file saved
in an earlier build will not open; import your Word file again or start a new book in this build.
