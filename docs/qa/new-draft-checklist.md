# New-draft QA checklist (#285)

Run from an **installed Windows build** (Arm-A-Rillo) after merge unless a row is marked
**manual-only**. Desktop vitest and Rust unit tests cover wiring; this checklist catches regressions
through the real stored path (save, reload, restart).

| #   | Verify                                                                                                                                                                                   | Covered by                                                                                                                                                                                                                   |
| --- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1   | **Book menu → New** creates a blank draft (`Untitled draft`); no `.docx` file picker and no import prompt ([#266](https://github.com/southline-tech/swarmDraft/issues/266)).             | Covered by: `App.test.ts` — `creates a blank draft from New in the book menu (#266)`                                                                                                                                         |
| 2   | **Toolbar draft picker → New** creates a blank draft; no `.docx` picker ([#243](https://github.com/southline-tech/swarmDraft/issues/243)).                                               | Covered by: `App.new-draft-285.test.ts` — `toolbar New creates a blank draft without opening the docx picker (#285)`                                                                                                         |
| 3   | **Ctrl+N** creates a blank draft; no import ([#266](https://github.com/southline-tech/swarmDraft/issues/266)).                                                                           | Covered by: `App.test.ts` — `binds Ctrl+N to create a blank draft (#266)`                                                                                                                                                    |
| 4   | **Open / import `.docx`** persists a new stored draft and makes it the active manuscript (outline + editor).                                                                             | Covered by: `App.test.ts` — `saves an imported .docx to the backend before opening it`; `App.new-draft-285.test.ts` — `imported .docx title appears in the toolbar draft picker (#285)`                                      |
| 5   | **Book menu → Recent** opens the chosen draft; flyout stays open until pick; menu closes after pick ([#104](https://github.com/southline-tech/swarmDraft/issues/104)).                   | Covered by: `App.test.ts` — `Recent submenu toggles without closing the book menu; picking a book closes it (#104)`                                                                                                          |
| 6   | **Toolbar DraftPicker** lists drafts and switching opens the correct stored draft ([#243](https://github.com/southline-tech/swarmDraft/issues/243)).                                     | Covered by: `App.draft-picker-243.test.ts` — `switches drafts from the picker`                                                                                                                                               |
| 7   | **Recent flyout** width is **220px** (not the 240px book menu list).                                                                                                                     | Covered by: `App.last-active-280.test.ts` — `Recent flyout uses 220px width with higher specificity than the 240px book menu`                                                                                                |
| 8   | **Restart** reopens the **last-active** stored draft, not merely the newest by `created_at` ([#280](https://github.com/southline-tech/swarmDraft/issues/280)).                           | Covered by: `manuscripts.rs` — `resume_prefers_last_opened_over_newer_created`; `App.new-draft-285.test.ts` — `cold start opens the manuscript returned by openLatestManuscript (#280)`                                      |
| 9   | If the last-active draft was **deleted**, restart falls back to the **most recently modified** remaining draft ([#280](https://github.com/southline-tech/swarmDraft/issues/280)).        | Covered by: `manuscripts.rs` — `deleted_last_active_falls_back_to_most_recently_modified`                                                                                                                                    |
| 10  | **Force-quit** immediately after **New** (before typing): relaunch still resumes the new blank draft.                                                                                    | manual-only (installed build; kill process right after New)                                                                                                                                                                  |
| 11  | While reopening, the **opening title** matches the draft being resumed (peek resume / progress), not another list row ([#280](https://github.com/southline-tech/swarmDraft/issues/280)). | Covered by: `App.last-active-280.test.ts` — `opening progress title matches peek resume candidate, not listManuscripts order`; `App.test.ts` — `cold reopen ob6 title uses the stored book name, not the product name (#80)` |
