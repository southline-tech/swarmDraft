# Installing swarmDraft (Author)

1. Download the latest installer from
   [Releases](https://github.com/southline-tech/swarmDraft/releases/latest) — file name like
   `swarmDraft_0.1.0_x64-setup.exe`.
2. Double-click the setup file. Windows may show **Windows protected your PC** because the app is
   not code-signed yet. Click **More info**, then **Run anyway**. You only need this extra step for
   unsigned builds.
3. Click **Install**, then **Finish**. Leave **Open swarmDraft now** checked if you want the app
   to start right away. No administrator password is required.
4. Updates: swarmDraft checks for new versions in the background and from **Check for updates…**
   in the book menu. When an update is ready, choose **Update now** to install and reopen the app
   (your manuscripts stay put). You can still install a newer setup from
   [Releases](https://github.com/southline-tech/swarmDraft/releases/latest) if you prefer.
5. Your data lives in `%APPDATA%\com.radiancelux.swarmdraft\`. Uninstalling from Settings removes
   the app but keeps that folder unless you tick **Also delete my manuscripts and settings** in the
   uninstaller.

For more detail (SmartScreen, coAuthor migration, uninstall pages), see
[install-windows.md](./install-windows.md).

Use **Send feedback** in the book menu or Settings if something goes wrong — we read every report.
