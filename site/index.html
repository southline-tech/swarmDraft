A manuscript editor built for bots and tracked changes

swarmDraft keeps your book on your machine. AI editor bots suggest edits you accept or reject — nothing silently changes your text.

Built for long-form writing with agents

Outline, section navigation, and review tools stay in sync while bots work through a local MCP server on your machine.

  • Suggest-only bots

    Agent edits arrive as tracked suggestions. You accept or reject each change — bots never rewrite your manuscript silently.

  • Local-first manuscripts

    Chapters and settings live in a SQLite database on your PC. Saves survive reloads, section switches, and restarts.

  • Per-agent MCP tokens

    Pair editor bots through the in-app localhost MCP server. Each agent gets its own token; secrets never leave your machine.

  • Open source

    Inspect, fork, and improve the desktop app on GitHub. Installers ship from Releases; this site links there instead of hosting binaries.
