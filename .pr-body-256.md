## Summary

- Per-agent draft access in SQLite (`manuscript_access_mode` + `agent_manuscript_access`) with Tauri IPC for list/set/grant/revoke and bulk actions.
- Agents toolbar window: selected-drafts checklist vs all drafts, bulk grant/revoke when agents are selected, batch banner + pre-selection after five pairings.
- MCP enforces access on manuscript-scoped tools and filters `list_documents`; pairing approve grants the active draft via `contextManuscriptId`.
- Comment reply and resolve persist in SQLite via `section_comment_reply` / `section_comment_resolve`; review meta returns `resolvedAt` and loads full threads for the mixed review list.
