# MCP cross-language fixture

Synthetic section (no real manuscript text) shared by the TypeScript content code and the Rust
MCP server.

- `synthetic-section.yupdate`: Yjs v1 update from `docToYDoc` (client id 1, deterministic).
- `synthetic-section.json`: the decoded doc, its `readView`, and Yjs mark keys.

Generated by `packages/docx/src/mcp-fixture.test.ts` (`UPDATE_FIXTURES=1 pnpm --filter
@coauthor/docx test`). `apps/desktop/src-tauri/src/content.rs` tests decode the same bytes and
must produce the same doc and read view.
